## 四、项目一句话简介

> 本系统以普通 USB 摄像头为输入，基于 MediaPipe 人脸/手部关键点，
> 实时识别**疲劳驾驶**（闭眼、打哈欠、低头）、**分心驾驶**（视线偏离、驾驶员离位）
> 与**违规驾驶**（打电话、抽烟）共 7 类危险行为，并输出分级告警、现场快照与统计报表。
>
> 技术实现为 Python 3.11 + PySide6 + MediaPipe + OpenCV，
> 架构上采用**分层 + 管道-过滤器 + 发布-订阅 + 微内核**四种样式组合，
> 并以「感知—决策—执行」参考模型组织业务流程。

## 五、快速验证（供评阅老师复核）

```bash
# 1) 安装依赖
pip install -r requirements.txt

# 2) 下载感知模型（一次性）
python tools/download_models.py

# 3) 环境自检
python run.py --self-check

# 4) 无摄像头也可体验完整功能（合成画面 + 内置行为脚本）
#    脚本跑完（约 30 秒）会自动收尾并给出会话报告；
#    若希望一直循环到手动停止，把 config/default.json 中
#    source.synthetic_duration 设为一个较大的秒数（如 9999）
python run.py --source replay --provider replay

# 5) 运行全部自动化测试
python -m pytest tests/ -q

# 6) 离线验证全部演示脚本是否符合预期（回归门禁）
python tools/probe_scenarios.py
```

> **当前验证结果**（2026-09-22，Python 3.11.15 / Windows）：
> `pytest tests/ -q` → **247 个用例全部通过**；
> `python tools/probe_scenarios.py` → **退出码 0，6 条脚本全部符合预期**。
